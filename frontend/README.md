# StatsHub Frontend

A modern React + TypeScript + Vite frontend for the StatsHub statistics dashboard.

## Setup

First, ensure you have Node.js 18+ installed. Then:

```bash
npm install
```

## Development

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` and will proxy API requests to `http://localhost:5132/api`.

## Building

Create a production build:

```bash
npm run build
```

## Features

- ⚡ Lightning-fast development with Vite
- 🎨 Modern React components with TypeScript
- 🔗 Integrated API proxy to .NET backend
- 📦 Production-ready build optimization
